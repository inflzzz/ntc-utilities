Feito para ser direto

O NTC Utilities mantém o trabalho no seu computador e deixa a interface cuidar do essencial.

Sem anúncios

Uma interface limpa, sem páginas intermediárias ou distrações.

Sem conta

Abra o app e use. Não há cadastro ou servidor obrigatório.

Processamento local

Histórico, preferências e arquivos permanecem no seu computador.

Dependências incluídas

O instalador já traz yt-dlp, FFmpeg e FFprobe.

Instalação

O instalador para Windows reúne tudo o que o app precisa para funcionar.

01Abra Releases

Acesse a versão mais recente pelo botão no topo da página.

02Baixe o setup

Escolha o arquivo NTC Utilities Setup para Windows.

03Instale e abra

Conclua o assistente e inicie pelo Menu Iniciar.
